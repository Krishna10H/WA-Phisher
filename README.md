# WA-Phisher
A Python-based remote browser sharing tool for WhatsApp Web. Uses Flask, WebSockets, Chrome DevTools Protocol, and Cloudflare Tunnel to provide browser screen streaming and remote interaction through a web interface. Built for cybersecurity research, browser automation experiments, and educational lab demonstrations.



# WhatsApp Web Remote Browser

A Python-based remote browser sharing project that provides a web interface for viewing and interacting with a Chrome browser running WhatsApp Web.

## Features

- Remote browser screen streaming
- Mouse and keyboard interaction
- WebSocket-based communication
- Flask web interface
- Cloudflare Tunnel integration
- Chrome DevTools Protocol integration
- Browser navigation controls

## Requirements

- Windows 10/11
- Python 3
- Google Chrome
- Cloudflare Tunnel

## Installation

```bash
pip install flask flask-sock websocket-client
```

## Usage

```bash
python remote_browser.py
```

Open the local admin interface displayed in your terminal.

## Technologies

- Python
- Flask
- WebSockets
- Chrome DevTools Protocol
- Cloudflare Tunnel

This project is intended for authorised security research and educational demonstrations only.
